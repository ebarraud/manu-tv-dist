# Applis TV de Manu

## 📺 Webcams Skaping

Affiche en plein écran les photos des webcams Skaping (stations de ski, lacs, mer…) sur une TV Android / Google TV :
en **économiseur d'écran** quand la TV ne sert pas, ou **quand on veut** depuis l'écran d'accueil.
Choix des webcams par massif et station, par thème (ski, lacs, plages…) ou par nom.

### Installer (5 minutes, sans ordinateur)

1. Sur la TV, ouvrir le **Google Play Store**, chercher **Downloader** (icône orange, par AFTVnews) et l'installer.
2. Ouvrir **Downloader**. Dans la barre d'adresse, taper le code **`CODE_DOWNLOADER`** puis **Go**.
   *(ou l'adresse complète : `https://raw.githubusercontent.com/ebarraud/manu-tv-dist/main/skaping-tv/skaping-tv.apk`)*
3. Le fichier se télécharge. Choisir **Installer**.
   Si la TV refuse : elle propose d'ouvrir les **Paramètres** → autoriser **Downloader** à installer des applis → revenir → **Installer**.
4. Choisir **Ouvrir**. L'appli se trouve ensuite dans **Applications** sur l'écran d'accueil (« Webcams Skaping »).
   Astuce : un appui long sur son icône permet de l'ajouter aux favoris.
5. Tu peux supprimer le fichier téléchargé quand Downloader le propose.

### Utiliser

- **▶ Lancer le diaporama** : un appui sur OK.
- Pendant le diaporama : **droite** = webcam suivante, **OK** = afficher/masquer le nom, **retour** = quitter.
- **Choisir par massif et station** : OK pour cocher un massif entier (toutes ses stations), **droite** pour déplier, **gauche** pour replier.
- **Réglages** : durée de chaque webcam, sens du balayage, ordre…

### Économiseur d'écran (facultatif)

Dans l'appli : **Activer l'économiseur d'écran (sans ordinateur)** et suivre les 3 étapes affichées
(activer le mode développeur, activer « Débogage USB », appuyer sur « Activer » puis autoriser).
C'est à faire une seule fois.

### Mises à jour

L'appli vérifie toute seule s'il existe une nouvelle version et affiche un bouton **« Nouvelle version disponible : installer »**.

Les photos appartiennent à Skaping et aux stations concernées : usage privé uniquement.
